# Scriptable v0.1 真机验收

本清单用于 iPhone / Scriptable 的人工验收。自动验证通过不等同于真机验收通过；完成本清单前不得 merge `main`、创建 Tag 或 Release。

## 准备

- 使用构建后的 `Pulse Calendar.js`，不要临时修改或把凭据粘贴进源码。
- 准备 Calendar-only Cloudflare Access Service Auth Client ID 与 Client Secret。
- 确认 iPhone 的地区、日期和网络状态正常。
- 截图或录屏前确认画面不含认证输入框、Keychain 值或其他私人信息。

## 首次配置

- [ ] 在 Scriptable App 内运行脚本，看到认证配置界面。
- [ ] Secret 使用安全输入框，不以明文回显。
- [ ] 保存后成功展示中号预览。
- [ ] 关闭并重新运行脚本，不需要把凭据写入脚本或参数。
- [ ] Scriptable 控制台不出现 Client ID、Client Secret 或完整 API 响应。

## Medium（首要验收）

- [ ] 标题月份与上海时区下的当前月份一致。
- [ ] 星期从周一开始，日期数量、首日偏移与实际月历一致。
- [ ] 今天、休息日、法定节假日、调休工作日、个人改班/改休的视觉状态正确。
- [ ] 备注只显示“排班 / 请假 / 加班”的存在性，不显示备注正文。
- [ ] 在线状态显示最近更新时间，文字无截断、重叠或溢出。

## Small / Large

- [ ] Small 完整显示当月日期，今天与离线状态可辨识，文字无重叠。
- [ ] Large 显示工作、休息、节日、调班、个人覆盖计数。
- [ ] Large 的节日名、调休班和个人改班/改休标签与 Pulse 页面事实一致。
- [ ] 三种尺寸切换时使用同一个月份和同一组逐日事实。

## 失败与缓存

- [ ] 在线成功一次后开启飞行模式，三种尺寸均回退到最后一次有效缓存。
- [ ] 缓存画面明确标注“离线”或“缓存”，不会伪装成实时数据。
- [ ] 删除或换成错误凭据时，若有缓存则仍可读缓存；无缓存时只显示安全的配置提示。
- [ ] 恢复网络与有效凭据后，组件回到在线更新时间状态。
- [ ] 失败过程不覆盖先前的有效缓存。

## 时间边界

- [ ] 跨上海自然日后，今天标记更新正确；离线缓存只推进展示用的“今天”，不改写日历事实。
- [ ] 跨月后请求新月份，不把上月缓存当作本月数据。
- [ ] 若官方节假日配置状态为未配置，客户端不自行推断或伪造官方节假日。
